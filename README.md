# view
Browser is only you have

View 是一个只读文件浏览器。桌面端可以打开、收藏和共享本地文件夹，静态网页版可以添加 HTTP autoindex 或 WebDAV 地址。局域网里的 iPad 可以通过浏览器查看电脑共享的全部目录。

## 本地运行

使用 Node.js 22.13 或更高版本和 pnpm 11.25.0，在仓库根目录安装依赖。

```sh
pnpm install --frozen-lockfile
```

| 命令 | 用途 |
| --- | --- |
| `pnpm dev` | 启动网页版开发服务器，在「添加位置」中输入远程目录地址。 |
| `pnpm desktop` | 构建共享界面并启动 Electron。首次启动会下载当前平台的 Electron。 |
| `pnpm build` | 检查 TypeScript 并生成静态站点，可将 `apps/web/dist/` 整个目录部署到 Web 服务器。 |
| `pnpm package:desktop` | 在 `dist/desktop/` 生成当前平台的桌面应用目录。 |
| `pnpm test` | 验证文件头识别、模型取样、桌面目录和 HTTP 共享服务。 |
| `pnpm test:browser` | 构建网页，用 Chromium 验证文件预览、Magika 识别和 WebDAV 登录后的媒体读取。可用 `pnpm exec playwright install chromium` 安装浏览器，或用 `VIEW_CHROMIUM_PATH` 指定已有的 Chromium 可执行文件。 |

## 从电脑上打开一张照片

点桌面端的「打开文件」，或把照片拖进 View 窗口。预览中按 ← 或 → 可以浏览同目录的照片和视频，按 Esc 会回到目录并选中刚看的文件。想把这个目录固定到首页，再点「收藏」。

也可以从系统文件管理器的「打开方式」选择 View。Windows 的便携版可手动选择 `View.exe`。Linux 先把应用目录放到常用位置，再执行随包的 `./install-open-with.sh`，即可为当前用户注册 View。移动应用目录后需重新运行脚本。

## 照片网格和缩略图

列表只读取目录信息。切换到网格后，View 为当前屏幕和邻近一屏的照片按需生成缩略图。点开照片始终读取原图。桌面端和局域网共享网页复用电脑上的缓存，iPad 浏览网格时只需下载小图。

每个最外层打开的目录在 View 的应用缓存目录中对应一个 SQLite 文件。比如先打开「照片」再共享「照片/旅行」，旅行照片的缩略图仍保存在「照片」的库里。重启后可以继续用，照片变化时会在下次浏览时更新。

当前支持 JPEG、PNG、WebP、GIF、AVIF 和 TIFF。缩略图按原比例生成，最长边 320 像素，动图取第一帧。静态网页版浏览外部 autoindex 或 WebDAV 时，仍从远程服务器按需读取图片。

## 登录 WebDAV

在静态网页版点「添加位置」，协议选 WebDAV，填入目录地址。打开受保护的目录时，输入 WebDAV 服务器的用户名和密码。当前支持 HTTP Basic 认证。登录只对这个标签页里的这个位置生效，图片、PDF 和音视频预览共用这次登录。点目录页的「退出登录」或重新加载网页后，再次打开受保护的目录需要重新登录。

部署静态网页时使用 HTTPS，本机开发也可使用 localhost。浏览器在这个站点的 Service Worker 中把视频的 Range 请求转给 WebDAV，服务器支持分段读取时即可按需取用视频数据。

## 打开后缀缺失或标错的文件

点开文件时，View 请求开头的 4 KiB 来选择查看器。例如，一份名叫 `旅行.jpg` 的 PDF 会进入 PDF 查看器，无后缀的 PNG 可以直接看图。列表和网格里的文件图标按名称匹配。

预览底部的「识别格式」可用 Magika 进一步判断文件类型。模型随应用分发，点按钮后才在本机的 Worker 中加载。对支持 Range 的大文件，识别时只取首尾各 4 KiB；只有完整内容不超过 8 KiB 时，才能在不支持 Range 的来源上运行模型。识别出可用的其他查看器时，可以直接切换。

## 从 iPad 看电脑上的照片

1. 在桌面端打开照片目录，点「HTTP 共享」。点「收藏」可以把目录固定在桌面首页，两项设置独立保存。
2. 进入「共享管理」，点「开启共享服务」。同一局域网内的 iPad 可以打开显示的地址并输入访问密钥，也可以扫码配对。
3. 登录后先看到所有已共享的目录。进入任意目录，点开照片即可预览。桌面端关闭某个目录的共享后，该目录下的旧链接也会失效。

独立部署的静态网页可以在「添加位置」中选择 HTTP autoindex 或 WebDAV。添加的地址保存在当前浏览器。两种网页版使用相同的目录和预览界面。
